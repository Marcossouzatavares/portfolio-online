# Checklist do perfil GitHub — marcossouzatavares23

Recomendações para o GitHub funcionar como extensão do portfólio, já que recrutadores costumam abrir o perfil logo depois do site.

## 1. README de perfil (`marcossouzatavares23/marcossouzatavares23`)

Crie um repositório com o **mesmo nome do seu usuário** — o GitHub renderiza o `README.md` dele na sua página inicial de perfil. Estrutura sugerida:

- 1-2 frases de bio: cargo-alvo + stack principal (mesmo texto do Hero do portfólio, para consistência).
- Stack principal em badges ou lista curta (React, Next.js, TypeScript, Tailwind CSS).
- 2-3 projetos em destaque, com link.
- Link do portfólio e do LinkedIn.

## 2. Nomes de repositório

Renomeie qualquer repositório com nome genérico (`teste`, `projeto1`, `final-v2`, `novo-projeto`) para um nome descritivo em kebab-case (`arara-delivery`, `ambiente-parintins`). Nome de repositório é a primeira coisa que um recrutador lê antes de abrir o código.

## 3. README por repositório

Cada repositório pinado deveria ter, no mínimo:
- O que o projeto faz (1 parágrafo).
- Stack usada.
- Como rodar localmente (`npm install` / `npm run dev`).
- Link do demo ao vivo, se existir.
- Uma frase sobre uma decisão técnica tomada (ex: "optei por SSG no Next.js para reduzir o LCP").

## 4. Repositórios pinados

Fixe de 4 a 6 repositórios no topo do perfil, priorizando os que também aparecem no portfólio (Green Factory 5.0, Arara Delivery, Site Ambiente Parintins) — consistência entre os dois aumenta credibilidade.

## 5. Atividade de commits

Não precisa ser diário, mas evite lacunas de vários meses sem nenhum commit público. Se os projetos reais (Green Factory 5.0, Ambiente Parintins) forem privados/institucionais, considere manter a Arara Delivery com commits regulares como prova de atividade contínua.

## 6. Pendências que dependem de você

- [ ] Confirmar se os repositórios de Green Factory 5.0 e Site Ambiente Parintins podem ser públicos (são projetos institucionais/acadêmicos).
- [ ] Publicar/confirmar link de demo ao vivo da Arara Delivery.
- [ ] Confirmar se o Site Ambiente Parintins ainda está no ar.
